# Scientific Palette Studio v1.0.0

Initial public release of the complete Codex Skill and browser-local website for scientific palette reuse.

- Extract main colors from PDFs, images or pasted screenshots.
- Generate tints, shades, tonal, multihue sequential and neutral-center diverging gradients.
- Download editable PowerPoint toolkits/themes, Origin JASC-PAL presets, color cards, gradients, CSV/JSON and complete ZIP kits.
- Use the local deterministic CLI or deploy the complete static app from `web/dist/`.
- English installation, usage, self-hosting, extension, licensing and validation documentation included.

Try the public app: https://scientific-palette-studio.majiabin7.chatgpt.site

Technical validation includes 20 Python checks and 11 Node checks, synthetic PDF/image/browser workflows and export-content verification. Native Origin import and native PowerPoint theme application remain untested; readability diagnostics are heuristics.

The complete release archive includes the Skill and website. The standalone web archive includes the ready-to-serve `dist/` folder and web source. No personal credentials, source papers or internal hosting identity are bundled.
