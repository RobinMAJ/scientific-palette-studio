# Scientific Palette Studio v1.1.0

A redesigned browser workspace for moving from a reference figure to reusable research colors and exports.

- Clearer reference controls and source canvas, larger editable swatches and consistent typography/spacing.
- Four result tabs: Main colors, Gradients, Figure preview and Downloads.
- PowerPoint, Origin and color-card/value downloads grouped with nearby use instructions.
- Keyboard tab navigation, continuous-scale activation, visible focus and a workspace skip link.
- Responsive swatches, full-width mobile shade samples and stacked export groups.
- English documentation, design rationale, current screenshots and bounded validation evidence.

Use the public app: https://scientific-palette-studio.majiabin7.chatgpt.site

The extraction mathematics, local CLI and native export engine are unchanged. The existing 11 Node checks passed; current browser tests covered image/PDF extraction, cropping, editing, tabs, grayscale preview, responsive reflow and downloaded package consistency. Native Origin/PowerPoint application sessions and full accessibility certification are not claimed.

The full archive contains the Skill and website; the standalone archive contains the ready-to-serve website. GitHub source and the independent Sites deployment were published separately.

# Scientific Palette Studio v1.0.0

Initial public release of the complete Codex Skill and browser-local website for scientific palette reuse.

- Extract main colors from PDFs, images or pasted screenshots.
- Generate tints, shades, tonal, multihue sequential and neutral-center diverging gradients.
- Download editable PowerPoint toolkits/themes, Origin JASC-PAL presets, color cards, gradients, CSV/JSON and complete ZIP kits.
- Use the local deterministic CLI or deploy the complete static app from `web/dist/`.
- English installation, usage, self-hosting, extension, licensing and validation documentation included.

Try the public app: https://scientific-palette-studio.majiabin7.chatgpt.site

Technical validation includes 20 Python checks and 11 Node checks, synthetic PDF/image/browser workflows and export-content verification. Native Origin import and native PowerPoint theme application remain untested; readability diagnostics are heuristics.

The complete release archive includes the Skill and website. The standalone web archive includes the ready-to-serve `dist/` folder and web source. No personal credentials, source papers or internal hosting identity are bundled.
