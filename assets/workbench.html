    Use the exports

    PowerPoint
    Open the editable toolkit and copy a swatch or gradient. Format Painter transfers the fill to your own shapes.
    For the theme: Design → Themes → Browse for Themes → palette.thmx. Office has six accent slots; all main colors remain in the toolkit.
    Origin
    Tools → Color Manager → Import from Files. Import main-colors.pal for categorical series, or a 256-color .pal for continuous colormaps.
    Set the actual data limits and the diverging midpoint in Origin; the palette file contains RGB values only.
    Everything runs locally in this file. Editing colors does not modify the original source paper or image. Main colors and derived gradients retain separate provenance.
